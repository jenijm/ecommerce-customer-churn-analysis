# E-Commerce Customer Churn Analysis

## Project Overview
This project analyzes customer churn in an e-commerce dataset using MySQL.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Project Tasks
- **Data Cleaning:** Handled missing values, removed outliers, and standardized inconsistent values.
- **Data Transformation:** Renamed columns and created `ComplaintReceived` and `ChurnStatus`.
- **Data Exploration and Analysis:** Analyzed churn rates, customer complaints, payment preferences, coupon usage, cashback, and order behavior.
- **Customer Returns Analysis:** Created a returns table and joined it with customer data to identify customers who churned and complained.

- `UPDATE` and `DELETE`
- `ALTER TABLE`
- `CASE WHEN`
- Aggregate functions
- `GROUP BY` and `HAVING`
- Subqueries
- `INNER JOIN` and `LEFT JOIN`
